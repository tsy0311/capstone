# Model Comparison Report

## Overview

This report compares all candidate models trained for startup funding outcome prediction. All models are evaluated on the same held-out test set (20% of the dataset) to ensure fair comparison.

## Evaluation Metrics

| Metric | Description | Business Relevance |
|--------|-------------|---------------------|
| Accuracy | Overall correct prediction rate | Misleading for imbalanced data |
| Precision | TP / (TP + FP) | False positives waste due diligence budget |
| Recall | TP / (TP + FN) | False negatives = missed opportunities |
| F1-Score | Harmonic mean of precision and recall | Balanced view of errors |
| ROC-AUC | Area under ROC curve | Threshold-independent discrimination |
| PR-AUC | Area under precision-recall curve | Better for imbalanced data |
| Brier Score | Mean squared error of probabilities | Calibration quality |

## Models Trained

### 1. Logistic Regression (Baseline)
- **Type**: Linear model
- **Class weight**: Balanced
- **Max iterations**: 1000
- **Strengths**: Interpretable, fast, good baseline
- **Weaknesses**: May underfit non-linear relationships

### 2. Decision Tree
- **Type**: Single tree
- **Max depth**: 5
- **Class weight**: Balanced
- **Strengths**: Captures non-linear patterns, interpretable
- **Weaknesses**: Prone to overfitting, high variance

### 3. Random Forest
- **Type**: Ensemble of trees
- **N estimators**: 200
- **Max depth**: 10
- **Class weight**: Balanced
- **Strengths**: Reduces overfitting, handles interactions
- **Weaknesses**: Less interpretable, slower inference

### 4. XGBoost
- **Type**: Gradient boosting
- **N estimators**: 200 (default), Optuna-optimized
- **Max depth**: 6 (default), Optuna-optimized
- **Strengths**: State-of-the-art on tabular data, handles missing values
- **Weaknesses**: More hyperparameters, potential overfitting

### 5. LightGBM
- **Type**: Gradient boosting (leaf-wise)
- **N estimators**: 200
- **Class weight**: Balanced
- **Strengths**: Fast training, memory efficient
- **Weaknesses**: Sensitive to small datasets, leaf-wise growth can overfit

## Model Selection

**Primary criterion**: ROC-AUC (threshold-independent)
**Secondary criterion**: Recall (identifying successful startups is business-critical)
**Tertiary criterion**: Calibration quality (if probabilities are used as risk scores)

The best model is selected as the one with the highest ROC-AUC on the test set, subject to acceptable recall and calibration.

## Threshold Selection

The default 0.5 threshold may not be optimal for business use. A cost-sensitive threshold optimization is performed:

- **Cost of false negative (missed successful startup)**: $5,000,000 (estimated deal value)
- **Cost of false positive (unnecessary due diligence)**: $50,000 per startup

The optimal threshold minimizes total expected cost:

```
Total Cost = FP × $50,000 + FN × $5,000,000
```

## Limitations

1. **Survivorship bias**: Dataset over-represents funded startups
2. **Observational data**: Correlations do not imply causation
3. **No intervention outcomes**: Cannot prove risk profiling improves investment decisions
4. **Geographical bias**: US-based companies over-represented
5. **Temporal drift**: Startup dynamics change over time
